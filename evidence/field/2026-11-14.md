# Appendix E.2: field observations, 2026-11-14

These observations come from the author's own Hermes Agent install, not from CI. A reader cannot rerun them, so no entry's confidence rests on them. They show that the behaviors the repros isolate also occur on a real install with real traffic.

## The install

- The official Docker image, `hermes --version` reporting `Hermes Agent v0.20.1 (2026.8.13)`, which is the v2026.8.13 tag pinned in `harness/images.json`.
- In production since August 2026: a webhook gateway that receives GitHub and Chatwoot deliveries, plus chat platforms.
- Read on 2026-11-14, local time (UTC−6), with read-only commands only. Nothing was restarted, written or sent.

## What was recorded, and what was not

Only counts, versions, paths inside the image, and the names of Hermes settings are recorded. Skill names, route names, hosts, logs, message content and configuration values are not. Where a count would reveal traffic volume, it is given as a share.
