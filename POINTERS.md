# Pointers

Documented Hermes Agent behaviors that still surprise operators. Each pointer links to the upstream source or docs at v0.23.1 (commit `3b421578`). These are not entries: upstream already describes them, so there is nothing to reproduce, only something to read before you are surprised. Pointers share the `E` numbering with entries, which is why some numbers appear on neither page: they are candidates that were cut or deferred.

- **E8. A `GH_TOKEN` or `GITHUB_TOKEN` in the gateway's environment is stripped from the subprocesses the agent starts.** Both are on the list removed from every spawned subprocess ([local_env_policy.py L413-L418](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/tools/environments/local_env_policy.py#L413-L418)). So `gh` run by the agent is not logged in, even when `gh auth status` works in your shell. `GH_TOKEN` is also on the credential blocklist ([L19-L45](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/tools/environments/local_env_policy.py#L19-L45)), so declaring it as an environment passthrough does not bring it back.
  - Sign `gh` in through its config directory instead. Kanban workers read a token from their own profile's `.env` ([kanban.md L68-L79](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/features/kanban.md?plain=1#L68-L79)).
  - `terminal.home_mode` decides which home that config directory lives in ([configuration.md L344-L364](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/configuration.md?plain=1#L344-L364)).
  - In the Docker image, make sure the directory is owned by the `hermes` user, which the agent runs as.
- **E10. The kanban dispatcher runs inside the gateway and starts agents on its own.** It ticks every 60 seconds by default and picks up ready tasks. With `review_dispatch: true`, also the default, it spawns the assigned profile as a reviewer for tasks in review; set `review_dispatch: false` for boards that only humans review ([kanban.md L314-L335](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/features/kanban.md?plain=1#L314-L335)). A ready task with no assignee is skipped, unless `kanban.default_assignee` is set ([kanban_watchers_dispatcher.py L96-L101](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/gateway/kanban_watchers_dispatcher.py#L96-L101)). Leaving the assignee off is how you keep a task you only want as a record out of an agent's hands.
- **E12. `HERMES_WRITE_SAFE_ROOT` guards `write_file` and `patch`, not the terminal tool.** The docs say so in [security.md L445-L447](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/security.md?plain=1#L445-L447), and the official image sets the root to `/opt/data` ([L426-L430](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/security.md?plain=1#L426-L430)). A blocked write returns `Write denied: ... is outside HERMES_WRITE_SAFE_ROOT` to the agent ([L414](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/security.md?plain=1#L414)). The model may still claim the edit succeeded; trust the file-mutation verifier footer over its summary ([L396](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/security.md?plain=1#L396)). Temporary files the agent writes with those tools belong under `/opt/data`, not `/tmp`.
- **E13. Mattermost is configured through environment variables first.** The manual setup puts `MATTERMOST_URL`, `MATTERMOST_TOKEN`, `MATTERMOST_ALLOWED_USERS` and the optional behavior settings in `~/.hermes/.env`; only some settings have a `config.yaml` spelling. When you check how a running gateway is set up, look in its environment, not in `config.yaml` ([mattermost.md L141-L174](https://github.com/NousResearch/hermes-agent/blob/3b421578588243f920886e6fe79a6faa87ea026e/website/docs/user-guide/messaging/mattermost.md?plain=1#L141-L174)).
